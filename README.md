# ERA5-Drought: <br/> Global drought indices based on ECMWF reanalysis

This repository contains the python code related to

> Keune J, Barnard C, Damasio da Costa E, Wetterhall F and Di Giuseppe F. ERA5–Drought: Global drought indices based on ECMWF reanalysis, Sci Data 12, 616 (2025). https://doi.org/10.1038/s41597-025-04896-y.

It consists of six jupyter notebooks that reproduce Figures 2–7 of the above publication. In addition, the notebook `create_barren_mask.ipynb` creates a barren area mask (glaciers, deserts, etc) using ERA5 data. 

The ERA5-Drought data can be downloaded via [this link](https://doi.org/10.24381/9bea5e16).
